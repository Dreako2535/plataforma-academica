## Gestión colaborativa de un proyecto con Git y GitHub

### Descripción

Este proyecto tiene como objetivo aprender y aplicar el uso de **Git y GitHub** para gestionar proyectos de software de manera colaborativa, permitiendo controlar los cambios realizados en el código y trabajar en equipo de forma organizada.

### ¿Qué es Git?

**Git** es un sistema de control de versiones distribuido que permite registrar los cambios realizados en los archivos de un proyecto. Facilita el seguimiento de las diferentes versiones, la creación de ramas y la recuperación de versiones anteriores.

### ¿Qué es GitHub?

**GitHub** es una plataforma que permite alojar repositorios Git en la nube. Facilita la colaboración entre desarrolladores, permitiendo compartir código, trabajar con ramas, realizar cambios mediante *commits* y gestionar proyectos de manera colaborativa.

### Objetivo

Aplicar los conceptos básicos de Git y GitHub para gestionar un proyecto de forma colaborativa, utilizando repositorios, commits, ramas y sincronización de cambios.
